Open-source mail sorting for macOS and Linux

Your inbox, organized by rules you write.

Postvak sorts any IMAP inbox with rules you can read: move mail, archive it, mark it read, or delete sign-in codes once you have used them. It sorts on your mail server, so every mail app you use sees the result, your phone included. Test every rule with a dry run, and undo any delete.

$ brew install postvak-app/tap/postvak

Rules, not an AI that sorts your mail.

Many AI mail clients hand every message to a model and let it decide. Postvak sorts with rules you can read, and lets AI help you write them.

See rules that work together

Predictable

The same mail gets the same outcome, every time. A model can file a message differently tomorrow, or delete one it misread.

Reviewable

A rule is a few lines of TOML. rules test shows what it would do. A message a rule acted on says which rule did it, and why, and postvak log lists every action.

Safe from the sender

Mail is written by strangers. A rule matches patterns, so instructions hidden in a message cannot change what it does.

Private

Your mail is never sent to a model to be sorted. Agents see only what you grant: by default senders and subjects, no bodies.

Free and fast

No tokens per message and no API key. Rules run on every sync, across years of mail, without a round trip to a model.

AI where it helps

An agent over MCP reads your inbox and proposes a rule. You approve it once; from then on the rule does the work.

Why not Thunderbird filters or Sieve?

Client filters stop when the app closes. Sieve sees a message once, as it arrives. Postvak keeps sorting without you, and acts on mail later: an hour after you read a sign-in code, or once a newsletter is a week old.

Agents propose, you approve

Let Claude draft the rule. Keep the decision.

Optional: Postvak works fully without any AI. It also ships an MCP server. An agent can look at your inbox, write a rule and show its dry run, but the rule stays disabled until you approve it in the window or on the command line.

It sees only what you grant. By default that is folders, senders and subjects: no message bodies, and no moving or deleting mail. Bodies, acting on mail and approving rules are each a scope you add on purpose, and --account hides your other accounts.

$ postvak mcp install claude-desktop
Agents over MCP

One engine, four ways in.

Mail window

A keyboard-driven window for reading mail and approving rules. No scripts, and no remote content until you allow it. postvak gui

Command line

Every feature, with --json for scripts. List, search, move, test rules.

MCP server

For Claude and other agents, scoped to what you grant. Senders and subjects by default.

Background sync

Headless at login, on a server or in Docker. Works with any IMAP server.
